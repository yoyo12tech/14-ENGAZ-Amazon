feat/user/S1-F11/ feat/cc/CC-1/

1. JwtConfigurationManager — Classical GoF Singleton (DP-5)
• Private constructor — NO @Component/@Service annotation
• Static getInstance() with double-checked locking or eager init
• Reads JWT secret + expiration from env vars (System.getenv) OR via singleton-bridge @PostConstruct
• Secret must be ≥ 32 bytes (44-char Base64 string) — shorter keys throw WeakKeyException
• Test: two calls to getInstance() must return the same reference (ref1 == ref2)

2. JwtService — Spring @Service using getInstance()
• Inject config via JwtConfigurationManager.getInstance(), NOT @Autowired
• generateToken(user) — embeds sub (email), uid (User.id), role, iat, exp claims
• validateToken(token) — returns claims or throws
• Algorithm: HMAC-SHA256

3. AuthHandler abstract class + 4 concrete handlers — Chain of Responsibility (DP-3)
• AuthHandler — abstract class with handle(AuthContext ctx) and setNext(AuthHandler next)
• TokenExtractionHandler — extracts Bearer token; 401 if missing
• SignatureValidationHandler — verifies JWT signature/expiry; 401 if invalid
• UserLoaderHandler — loads user from PostgreSQL; 401 if not found
• RoleAuthorizationHandler — checks role for endpoint; 403 if insufficient

4. JwtAuthenticationFilter — doFilterInternal() wires the chain
• Extends OncePerRequestFilter (Spring Security)
• Inside doFilterInternal: construct chain head → call head.handle(new AuthContext(request))
• On chain failure: write 401/403 to response, do NOT call filterChain.doFilter()
• On success: populate SecurityContextHolder, then call filterChain.doFilter()

Note: Do NOT replace Spring Security's filter chain. Your AuthHandler chain lives inside doFilterInternal — Spring Security's
chain is the outer wrapper.

5. S1-F10 Register + S1-F11 Login endpoints (user-service)
• POST /api/auth/register (public) — BCrypt hash, role=CUSTOMER, 201 + token
• POST /api/auth/login (public) — BCrypt verify, 200 + token; 401 for both wrong-pw AND unknown-email
• Both return: {token, expiresIn}
• Token payload: sub=email, uid=User.id (Long), role, iat, exp
